# homerunPET (霍曼宠物) — лоток CS106 в Home Assistant

Своя интеграция для самоочищающегося лотка homerunPET CS106 (китайский аккаунт приложения 霍曼宠物).
Работает через облако производителя: локального управления у этого лотка нет (см. ниже).

## ⚠️ Вход в аккаунт: только токен приложения

Аккаунт привязан к китайскому номеру, на который может не прийти SMS. Новый вход в облако
**может выкинуть телефон из аккаунта**: приложение по ответу с кодом `4001` разлогинивается
и просит войти заново. Поэтому интеграция по умолчанию **не логинится**, а берёт токен,
которым уже пользуется приложение.

Проверено 05.10.2026: тот же токен с второго клиента (чтение статуса и настроек) работает
одновременно с телефоном, приложение из аккаунта не выкидывается.

Вход по телефону и паролю тоже есть, но только если явно отметить
«Нет токена: войти по телефону и паролю (рискованно)». При повторной авторизации (reauth)
интеграция просит только новый токен и сама никогда не логинится.

### Как взять токен (без root)

Приложение само пишет свои запросы в системный журнал Android (тег `HM_Request`), вместе с
заголовком `x-token`.

1. Включить на телефоне «Отладку по USB», подключить к Mac, разрешить доступ.
2. Открыть 霍曼宠物 и зайти в карточку лотка.
3. В терминале: `adb logcat -d | grep -m1 -oE 'x-token: [^ ]+' | cut -d' ' -f2`

Токен не публиковать и не коммитить. Срок жизни в коде приложения не задан, обновления нет;
если облако его отклонит, Home Assistant предложит ввести новый.

## Установка

```sh
sh router/homeassistant/homerun-deploy.sh   # копирует в /config/custom_components и перезапускает HA
```

Затем «Настройки → Устройства и службы → Добавить интеграцию → homerunPET», вставить токен,
регион «Китай». В HACS как отдельный репозиторий пока не оформлено: интеграция лежит внутри этого репо.

## Что есть в Home Assistant

| Сущность | Откуда на лотке |
|---|---|
| `number` Задержка уборки после ухода кошки (1–60 мин) | свойство `AutoShovel.time`; перед записью свежее чтение, `Switch` остаётся как на лотке |
| `switch` Автоуборка | `AutoShovel.Switch`; так же, задержка остаётся как на лотке |
| `switch` Ночной режим | `NightMode.Switch`; окно `StartTimeInt`/`EndTimeInt` (сек. от полуночи) остаётся как на лотке |
| `switch` Защита от детей / Защита котят / Автодосыпание / Автоприкапывание | `ChildLock` / `KittenProtection` / `AutomaticSandAddingSwitch` / `AutomaticBurial` |
| `button` Убрать сейчас | действие `ManualShovel`, тело `{"value":null}` |
| `button` Разровнять наполнитель | действие `ManualLayingCatLitter`, тело `1` |
| `button` Досыпать наполнитель | действие `AutomaticSand`, тело `1` (одна порция) |
| `sensor` Работа | `MachineTask`: ожидание, уборка, досыпание, чистка, разравнивание, вход поднят, возврат, кошка внутри |
| `sensor` Визитов сегодня (+ список визитов в атрибутах), Последний визит, Вес кошки, Длительность визита | `/app/v1/devicesToiletData/list` (вес в граммах, длительность в секундах) |
| `sensor` Уборок сегодня, Последняя уборка | `/app/v1/devicesCleanData/list` |
| `sensor` Ошибок (ключи в атрибуте `codes`), `binary_sensor` Неисправность | `/app/v1/devicesExceptionStatus/list` (ключи локализации приложения) |
| `binary_sensor` Мусорный ящик полон / Мало наполнителя в баке / в барабане | `LitterMargin.Dustbin` / `SandBucket` / `Drum` (`true` = норма) |
| `binary_sensor` В сети | `/app/v1/devices/status` (`1` = онлайн) |
| `sensor` Прошивка (+ последняя версия) | `/app/v1/devices/versionInfo` |
| `event` Визит кошки | новый визит в списке визитов (после полуночи учитывается и вчерашний день); данные: время, вес, длительность |

Если текущую настройку прочитать не удалось, запись не отправляется (ошибка в HA), чтобы сбой связи
не перезаписал задержку или ночное окно значением по умолчанию.

Опрос: раз в минуту статус, задача, ёмкости, визиты, уборки и ошибки (~7 запросов на лоток);
настройки и прошивка раз в 10 минут и сразу после изменения из HA. Пока лоток не в сети,
управление недоступно: облако не может передать ему команду.

Не вынесены намеренно: `Operate` (поднять/сбросить вход), `SystemReset` (сброс к заводским),
`RemoteReboot`, `DeviceMode` и `ThresholdAddLitter` (значения не подтверждены на этой прошивке).

## Протокол (из APK 3.6.7 и живой проверки)

- Хост китайского аккаунта: `https://api.homerunsmart.com` (есть `eu/us/sgp/ind/sa`-варианты;
  `*.homerunsmartapi.com` — новый API v2 для лотков собственной разработки, CS106 его не использует).
- Все запросы — `POST /app/v1/...`, тело `{"data": {...}, "timestamp": "<unix sec>", "sign": "<hex>"}`.
- Подпись: `sha256( "k=v&" по ключам data в порядке убывания + "appKey=<APP_SECRET>&timestamp=<ts>" )`,
  значения как `String.valueOf` в Java. `APP_SECRET` — константа приложения (`api/const.py`).
  Проверено: 20 из 20 подписей приложения совпали, сервер принимает подписи клиента.
- Заголовки: `x-token`, `X-Application-Id`, `x-lang`, `X-Client-*`. Обёртка ответа
  `{"code":"200","msg":...,"data":...}`; `4001` — токен недействителен.
- CS106 — лоток с Wi-Fi модулем EZVIZ (код модели `C5F40390`). Управление идёт через прокси
  `POST /app/v1/devices/control` с `data = {url: "/api/v3/device/otap/prop" | "/api/v3/device/otap/action",
  method: "GET" | "PUT", headers: "<JSON: deviceSerial, localIndex 0, resourceCategory global,
  domainIdentifier customDomain, propIdentifier | actionIdentifier>", body: "<JSON>"}`; ответ
  `data = {meta: {code: 200}, data: <значение>}`.
- Пароль при входе: `MD5(appkey + пароль + соль)[7:27]` (`api/signing.py`).

Проверено вживую 05.10.2026: чтение всех настроек, ёмкостей, визитов и уборок; запись
`AutoShovel` (тем же значением, 5 мин) принята облаком. Команды «Убрать сейчас», «Разровнять»,
«Досыпать» в живую не нажимались: тела сверены с кодом приложения
(`DeviceCatLitterBoxFragment.SetManualShovel` и др.).

### Не подтверждено

- Часовой пояс времён визитов: облако отдаёт время без зоны; интеграция считает его временем
  HA (Europe/Moscow, его же шлёт в `X-Client-Time-Zone`). Подтвердит один визит: сравнить
  «Последний визит» в HA с реальным временем.
- `unique_id` записи — минимальный id семьи аккаунта: если войти в другую семью с меньшим id,
  повторная авторизация откажет «токен от другого аккаунта» — тогда удалить и добавить заново.

## Локальное управление: нет

С роутера MikroTik видно одно постоянное TCP-соединение лотка с облаком EZVIZ (Hikvision,
Ханчжоу) на порт 8843. TLS-рукопожатие сервер не принимает и сам ничего не шлёт: это закрытый
протокол EZVIZ, а не MQTT открытым текстом. Подменить облако локальным брокером, как у PetKit,
не получится. Окончательно подтвердить содержимое трафика можно дампом с роутера (у пользователя
`claude` на RB5009 нет прав на `/tool sniffer`).

```sh
cd router/homeassistant/homerun-tests && python -m pytest -q   # нужны pytest, pytest-asyncio, aiohttp
```

Клиент облака (`api/`) не зависит от Home Assistant и проверяется на обезличенных ответах
облака из `fixtures/` (серийный номер, ID семьи и комнат заменены).
